# 成人血压测量与高血压诊断语料

本数据集用于医生查询成人血压测量、诊断确认、适用范围和例外分流。它不提供处方服务，也不为个体选择药物或剂量。提问涉及妊娠、未成年人、超出所列共病指南范围的管理，或具体患者用药时，评测标记为范围外或要求拒答。

## 文件和生成

`evidence.jsonl` 是唯一供检索系统建立知识库的文件。`questions.jsonl` 是评测专用文件，其中 `gold`、`expected`、`expected_groups`、`reason` 和其他标注字段不能输入检索器、生成器或重排器。`sources.json` 保存来源、版本核查时间和访问状态。运行 `python build_clinical_corpus.py` 会从脚本内的结构化摘要重建三个 JSON 文件；脚本不下载或缓存指南全文。

证据按来源可追溯到指南章节、推荐编号、表格或综述摘要。每条 `text` 是简短的中文释义，保留回答所需的数值、条件、时序和例外；不批量复制指南正文。诊断阈值及方法按原发布机构分别编码，AHA/ACC、ISH、NICE 与 USPSTF 的范围和用途不会合并成单一规则。综述结论作为研究证据单独标记，不冒充临床推荐。

## 来源与版本

版本核查日期为 **2026-11-18**。语料包含80条证据：NICE NG136 27条、ISH Global Hypertension Practice Guidelines 2026 20条、AHA/ACC 2025成人指南16条、USPSTF 2021筛查建议7条，以及两项系统综述各7条和3条。

## 评测集设计

题库共62题：36道开发题、26道冻结测试题。`group`为每个独立意图组标识，同组变体不得跨拆分；本版本每组一道问题。题型涵盖测量准备、阈值分类、筛查、确认路径、跨指南比较、特殊人群和例外、系统综述结果、库内证据不足及范围外请求。

每题的 `supplied` 是可信的预置上下文模拟，可以为空、只含部分联合金标、含完整金标，或提供相近但不支持所问来源/结论的材料。`initial_need` 在全部必要金标已预置时为 `false`；缺少联合证据或库内不可答时为 `true`；范围外请求设置为 `scope_out:true`，应在额外检索前拒绝。约分条目使用 `complexity:"single"`，至少两条共同必需来源使用 `"multi"`，不支持或范围外请求使用 `"out"`。

`gold` 列出回答所需的联合证据ID。对无法从语料回答的题目，`gold` 可以为空；范围外题目有时保留一条明确说明适用范围的依据，仅供安全解释为何转介到专门指南。`expected_groups` 将每个答案要点与可接受的短语变体放在同一组，按语义检查关键数值、条件与否定；`expected` 是各组首选短语，不能替代对最终回答语义和引文覆盖的核读。`reason` 只为盲评组织与数据审计服务，不供系统读取。

## 解释限制

本语料覆盖的成人指南并非同一机构的统一规则集。AHA/ACC的130/80第1期分类、ISH 2026的Elevated BP分类、NICE的140/90诊断确认及USPSTF筛查建议针对不同目的，问题中的来源标签不可省略。系统综述的敏感度、特异度来自异质研究汇总，需保留来源和分析阶段。

开发/测试划分按查询意图组织，短语重写不跨拆分。题目为研究者构造，不能代表真实门诊病例分布；本数据集不包含儿童、妊娠、急症处置细节、袖带品牌验证清单、个体治疗方案或完整继发性高血压诊疗流程。遇到这些事项应明确指出证据边界并拒绝具体决策。
